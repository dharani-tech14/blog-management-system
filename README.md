# Blog Management System

A full-stack Blog Management System developed as part of the Full Stack Development Internship at Codomax Digital Solutions.

## Features

- Add Blog Posts
- View All Blogs
- Edit Existing Blogs
- Delete Blogs
- Responsive User Interface
- Form Validation
- Smooth Animations and Hover Effects

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

## Project Structure

```
blog-management-system/
│
├── css/
├── js/
├── public/
├── server.js
├── package.json
├── index.html
└── add-blog.html
```

## Installation

Clone the repository

```bash
git clone https://github.com/dharani-tech14/blog-management-system.git
```

Install dependencies

```bash
npm install
```

Run the server

```bash
node server.js
```

Open in browser

```
http://localhost:3000
```
